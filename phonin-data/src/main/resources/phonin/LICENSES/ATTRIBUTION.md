listed below. Regenerate with `./gradlew refreshDatasets` (or
`python3 tools/build_dataset.py`). See `../MANIFEST.json` for exact versions,
SHA-256 checksums, and per-file row counts.

## Notes
- **words.hk word-level data is NOT bundled** automatically: words.hk distributes its
  CSV only via request (https://words.hk/faiman/request_data/). Place a TSV at
  `build/downloads/wordshk/words.hk.tsv` (`headword<TAB>jyutping`) and re-run to enable
  `raw/cantonese-word.tsv`. Character-level Cantonese (Unihan + wordshk-tools) is always present.
- Shuangpin encoders were ported verbatim (as algebra rules) from the RIME
  `rime-double-pinyin` schemas; per RIME's BSD-3-Clause license, modification and
  redistribution are permitted with the license retained.
- Korean (Hangul) romanization is computed algorithmically (Revised Romanization,
  per-syllable); no third-party data is used for the 11,172 Hangul syllables.
